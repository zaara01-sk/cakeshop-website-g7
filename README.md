#🍰cakeshop-website-g7
Web Development Project - Professional Cake Shop Website.
**Course:** CA-231-FP Project on Web Designing (12 Sessions - 2 Credits)  
**Team:** 4 Members | **Duration:** 4 Weeks | **Institution:** Abasaheb Garware college.

## 🎯 Project Overview
A front-end-focused, interactive cake shop website with a booking system for cake-making classes. Built using HTML5, CSS3, Bootstrap 5, JavaScript ES6+, and jQuery with professional enhancements.

## 👥 Team Members & Responsibilities

| Member | Role | Pages | Specialization |
|--------|------|--------|----------------|
| **Member A** | Homepage & Forms Lead | `index.html`, `contact.html` | Frontend UX, Form Validation |
| **Member B** | Products & Design Lead | `products.html`, `about.html` | Visual Design, Content |  
| **Member C** | Classes & Cart Lead | `classes.html`, `cart.html` | Functionality, Booking System |
| **Member D** | Integration & Performance | Global Features | Architecture, Optimization |

## 🛠️ Technology Stack

### Core Academic Requirements ✅
- **HTML5** - Semantic structure and accessibility
- **CSS3** - Advanced styling and animations  
- **Bootstrap 5** - Responsive framework and components
- **JavaScript ES6+** - Interactive functionality (8+ functions)
- **jQuery** - DOM manipulation and animations

### Professional Enhancements 🚀
- **AOS Library** - Scroll-triggered animations
- **Swiper.js** - Professional image galleries
- **GSAP (Basic)** - Hero section animations
- **LocalStorage** - Cart and booking persistence
